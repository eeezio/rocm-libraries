# FA-v3 deterministic backward — MI355X 实测（20 config）

**日期：** 2026-07-27  **机器：** AMD Instinct MI355X (gfx950)，ROCm 7.2.0 / HIP 7.2.26015
**代码：** composable_kernel `develop` @ `770725559a`（persistent scheduling 已合入，见 #7450）
**构建：** `tile_example_fmha_bwd`，FMHA BWD codegen = `--receipt 400 --optdim 64`（varlen bwd，含 deterministic 实例）
**运行：** `-v=0 -mode=1(group/varlen) -prec=bf16 -d=64 -b=4 -deterministic=1 -warmup=10 -repeat=50 -timer=gpu`
**选中 kernel：** 全部 20 个 config 均命中同一实例
`fmha_bwd_d64_bf16_group_b32x256x64x32x64x32x32x64x64_r1x4x1_r4x1x1_r1x4x1_w16x16x32_w16x16x32_o1_maxq0_npad_nbias_ndbias_mask_ndropout_deterministic_trload_gfx950`

mask 语义：full causal = bottom-right（`-mask=b`）；SWA = bottom-right 滑动窗口（`-mask=b:W,0`），Set A W=2048，Set B W=2047。
per-batch seqlen 显式给定 4 个相同值，避免 group mode 默认的随机长度，保证可复现。

## 4. 观察

1. **SWA 从 9/10 变成 10/10。** #13（1024²）从 1.07× 提升到 1.49×，是本次唯一从 miss 转 PASS 的 SWA config。
2. **full-causal 仍是主要缺口，但全线上移。** 从文档的 0.83×–1.16× 提升到 1.00×–1.59×；最难的 #8（16384 full）由 0.83× → 1.02×，首次追平 H100；#16 恰好持平（1.00×）。**8 个 full-causal 仍未达标。**
3. **#10 / #11 比文档的 best-of-both 略慢**（0.94× / 0.99×）。原因清楚：文档里这两个 config 的最优分支是 **exp1**（3.434 / 3.248），persist 分别是 4.510 / 3.969。develop 上 deterministic 强制走 persistent（`kUsePersistent = kIsDeterministic && !kUseQrQtrDorPipeline`），拿不到 exp1 的优势。不过 develop 的 persistent 已远好于文档里的 persist 数字（3.644 vs 4.510，3.275 vs 3.969），在 #12 上甚至同时超过两个分支（3.089 vs exp1 3.357 / persist 3.861）。
4. **Set B SWA 的时间对 S_kv 非单调**：#12（S_kv=12288, 3.089ms）快于 #11（S_kv=8192, 3.275ms）。三次重跑稳定复现，不是噪声，属于 persistent 切分/占用率效应。文档里这两个是单调的（3.248 / 3.357）。
5. **提升幅度无法拆分。** 相对文档的 1.07×–1.39× 改善同时包含 (a) MI355X vs MI350 的硬件差（文档 caveat 说 ~10–20%）和 (b) 2026-06-26 之后 develop 上的代码改动。要拆开需要在 MI350 上跑同一 build。

## 5. 复现方式

```bash
# 构建（example/ck_tile/01_fmha/CMakeLists.txt 中 FMHA_BWD codegen 改为 --receipt 400 --optdim 64）
cmake -S projects/composablekernel -B <build> -GNinja -DCMAKE_BUILD_TYPE=Release \
      -DCMAKE_CXX_COMPILER=/usr/bin/hipcc -DGPU_TARGETS=gfx950 -DBUILD_TESTING=OFF
ninja -C <build> -j60 tile_example_fmha_bwd

# 运行
<build>/run_fa_v3_bwd_20cfg.sh <outdir>
```

单条命令示例（#8）：

```bash
tile_example_fmha_bwd -v=0 -mode=1 -prec=bf16 -d=64 -b=4 -h=128 -h_k=16 \
  -s=16384,16384,16384,16384 -s_k=16384,16384,16384,16384 \
  -mask=b -deterministic=1 -warmup=10 -repeat=50 -timer=gpu
```
